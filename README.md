# Proxy Fight Club

A humorous office-themed brawler built in Unity. Designed around the prompt words "Shareholder" and "Versus," this game tasks players with fighting their way up the corporate ladder by literally brawling with colleagues in a chaotic office setting.

## Core Gameplay Mechanics

* **Corporate Brawling:** Office-themed melee combat where you must physically battle coworkers to secure your status and climb the corporate ladder.
* **Humorous Setting:** A tongue-in-cheek take on office politics and shareholder value, transforming everyday workplace tension into a literal beat-'em-up.

## Tech Stack & Development Context

Developed for a school assignment, this was my very first production-level project using **Unity**. Driven to explore the engine's ecosystem, I used this project as a sandbox to learn and implement a wide variety of features.

**Engine:** Unity
**Language:** C#
**Core Focus:** Custom Component Workflows, Animation, Specialized Input Logic

## Key Challenges & Learnings

The primary challenge of this project was rapidly overcoming Unity's learning curve while delivering a playable game. Key technical achievements include:

* **Custom Component Workflows:** Engineering modular and reusable component workflows from scratch to handle gameplay logic and combat stats.
* **Hand-Crafted Animation:** Rigging and animating hand-crafted arm movements to give the brawling mechanics a distinct, punchy feel.
* **Specialized Input Logic:** Designing custom input systems to ensure the melee combat felt responsive and chaotic yet controllable.

## Getting Started

1. Clone this repository to your local machine.
2. Ensure you have **Unity** installed (check the `ProjectSettings/ProjectVersion.txt` for the specific editor version).
3. Open the project via the Unity Hub.
4. Load the main scene in the `Scenes` folder and press **Play** in the editor.
